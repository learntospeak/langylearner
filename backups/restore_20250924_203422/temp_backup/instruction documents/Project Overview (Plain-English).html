# Project Overview (Plain-English)

## What this is

A small web app for learning Japanese. You open an HTML page in a browser and it shows
lesson steps. You type romaji (like 'kon'nichiwa') and the app turns it into kana (こんにちは).
It can also speak lines, and in some browsers listen to your voice.

## How typing works (simple)

When you type romaji, the app uses a library called WanaKana to convert it into kana.
Example: typing 'kon'nichiwa' becomes こんにちは. The code also adds some small helpers: it
corrects common mistakes (like わ vs は), handles small っ, and compares what you typed to the
answer using kana (so punctuation like 。 won’t block you).

## Audio and voice

Text-to-speech (TTS) uses the browser’s built-in voices. It works on most devices, but the
first sound usually requires a tap. Speech recognition (listening) only works on some
browsers like Android Chrome. iOS Safari does not support it; the app shows a friendly
fallback.

## Deploying (very short)

1) Put your files in a GitHub repo. 2) Enable GitHub Pages to host them. 3) On your phone,
open the Pages link and test typing + sound. 4) For an Android app, turn the site into a PWA
and use Bubblewrap to package it.

## Glossary (super short)

- **Relative path**: `stories.json` (works from any folder). Not `/stories.json` (root-only).
- **PWA**: Website that can be installed like an app.
- **TTS**: Computer voice that reads text.
